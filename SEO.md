# Grow Google traffic for AiResumeDraft (USA, India, Europe)

This site now includes stronger on-page SEO. Rankings still need Google discovery and authority over time—no tool can guarantee #1 results overnight.

## Already implemented on the website
- Per-page titles and meta descriptions
- Canonical URLs + Open Graph / Twitter cards
- JSON-LD (Organization, WebSite, SoftwareApplication) with USA / India / Europe `areaServed`
- `robots.txt` + updated `sitemap.xml`
- Geo-focused guides:
  - `/resources/us-resume-format`
  - `/resources/india-resume-format`
  - `/resources/european-cv-vs-resume`

## Do this in Google Search Console (required)
1. Open [Google Search Console](https://search.google.com/search-console)
2. Add property: `https://airesumedraft.com`
3. Verify ownership (HTML tag or DNS)
4. Submit sitemap: `https://airesumedraft.com/sitemap.xml`
5. Use **URL Inspection** on the homepage and the three geo guides → **Request indexing**
6. In property settings, review international targeting if shown (for a domain property, Google mainly uses content/locale signals)

## Optional: paid promotion with Google Ads
Organic SEO is free but gradual. For faster traffic in USA / India / Europe:
1. Open [Google Ads](https://ads.google.com) (separate from AdSense)
2. Create a Search campaign
3. Locations: United States, India, and selected European countries
4. Keywords examples:
   - free AI resume builder
   - ATS resume template
   - resume format India
   - US resume examples
   - European CV template
5. Point ads to `/`, `/builder`, and the matching `/resources/...` guides

## Content cadence that helps rankings
- Publish or improve one useful guide every week
- Earn links by sharing guides on LinkedIn / relevant communities (no spam networks)
- Keep Core Web Vitals healthy (fast Hostinger hosting, compressed assets)

## Measure
- Search Console → Performance (queries, countries)
- Filter countries: United States, India, United Kingdom, Germany, France, etc.
